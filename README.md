# AALKC Mail

High-end, futuristic webmail interface for Amanat Al-Kalima Company (AALKC).
Glassmorphism, dark-mode aesthetics, spring micro-interactions, and enterprise-grade
cloud architecture (Cloudflare Workers - D1 - R2 - Hostinger Mail API).

Open `aalkc-mail-nebula.html` in any modern browser - the prototype is fully
self-contained (fonts, icons, and sample data embedded).
