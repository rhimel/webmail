# AALKC Mail

Webmail interface artifacts for Amanat Al-Kalima Company (AALKC).

- `aalkc-mail-nebula.html` — Nebula Edition: dark glassmorphism, obsidian aurora canvas.
- `aalkc-mail-industrial.html` — Industrial Silver v3: brushed-steel silver panels over
  the dark navy (#0E335C) chassis, 45-degree chamfered corners, octagonal avatars,
  spring micro-interactions, zero glow, and the custom AALKC / AALKC Kufi font
  family exclusively (embedded, no external fallback fonts).

Enterprise-grade cloud architecture (Cloudflare Workers - D1 - R2 -
Hostinger Mail API) with a TLS/DKIM/SPF trust strip per message.

Open either file in any modern browser - each artifact is fully
self-contained (fonts, icons, and sample data embedded).
